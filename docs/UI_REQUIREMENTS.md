# UI 设计需求

## 设计风格

- 定位：科技企业、工程项目、企业级应用
- 关键词：科技感、专业感、简洁、易用
- 主色：`#1677FF`
- 成功：`#52C41A`
- 警告：`#FAAD14`
- 危险：`#F5222D`
- 背景：`#F5F7FA`

## 小程序页面

- 首页：Banner、解决方案中心、产品中心、典型案例、企业优势、联系我们。
- 产品中心：搜索框、分类 Tab、产品卡片。
- 产品详情：产品图片、名称、型号、简介、技术参数、附件，底部设备询价与分享按钮。
- 解决方案：卡片式布局，展示封面图、标题、简介。
- 案例中心：卡片式布局，展示项目图片、项目名称、项目地点。
- 销售中心：询价、报价、模板、AI 助手、浏览记录。
- 报价页面：步骤向导，项目信息、新增测项、选择设备、生成报价、导出 Word。
- AI 助手：聊天式界面，第一阶段仅占位。

## PC 后台

- 布局：左侧菜单、右侧内容、顶部导航。
- 菜单：工作台、产品管理、方案管理、案例管理、询价管理、报价管理、模板管理、AI 知识库、系统设置。
- 列表页：搜索、筛选、分页。
- 删除：二次确认。
- 编辑：自动保存草稿预留。
- 报价：实时计算金额。
- 附件：在线预览和下载预留。
- 二维码：一键生成和下载预留。
